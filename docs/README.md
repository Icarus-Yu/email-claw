# EmailClaw 文档目录

本目录收纳项目过程文档、对接文档和实验报告，根目录只保留运行项目必需的工程文件与 README。

## 目录说明

- `project/`：课程项目过程材料、需求规格说明书、选题与建组报告。
- `integration/`：飞书前端、OpenClaw 等外部系统接入文档。
- `reports/`：实验报告模板、团队报告、个人报告和报告生成结果。
