# EmailClaw 学习笔记目录

这个目录用于系统学习 JavaScript、TypeScript、Node.js 后端项目结构，以及 EmailClaw 项目的架构和面试讲述方式。

建议学习顺序：

1. `01-js-ts-knowledge-map.md`
   - 从初学者视角建立 JavaScript / TypeScript / Node.js 的知识体系。
   - 重点理解：JS 是运行语言，TS 是开发期类型系统，Node.js 是服务端运行环境。

2. `02-typescript-project-reading.md`
   - 学习一个 TypeScript 项目应该怎么看。
   - 重点理解：`package.json`、`tsconfig.json`、入口文件、源码目录、构建产物、分层架构。

3. `03-emailclaw-architecture.md`
   - 结合 EmailClaw 项目讲整体架构。
   - 重点理解：IMAP 邮件监听、规则引擎、Agent 分析、Prisma 持久化、飞书交互闭环。

4. `04-interview-cheatsheet.md`
   - 面试时可以直接复述的项目介绍、技术亮点、追问回答。

学习目标：

- 能说清楚 JS 和 TS 的关系。
- 能看懂一个 TS 后端项目从哪里启动。
- 能说清楚 EmailClaw 的主业务链路。
- 能解释 TypeScript 类型在项目中的作用。
- 能从工程角度讲 AI / Agent / OpenClaw 接入的可靠性设计。
- 能诚实说明当前项目与 MCP 的关系，以及未来如何改造成 MCP Server。
